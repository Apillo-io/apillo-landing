# Apillo Landing

Türkiye'nin KOBİ'lere güç veren teknoloji şirketi.

## 🏢 Apillo Hakkında

Apillo, küçük ve orta ölçekli işletmelerin dijital operasyonlarını yöneten, tek veri mimarisine bağlı bir ekosistem kuruyor.

**Vizyon:** KOBİ'lerin dijital dönüşümünü hızlandırmak, veri ekosistemleri oluşturmak.

**Hedef Sektörler:** Kafeler, Kuaförler, Çiçekçiler, Mikro Turizm, Bungalov Rezervasyonları

## 🚀 Tech Stack

- **Frontend:** Next.js 14 (App Router), TypeScript, TailwindCSS
- **Backend:** Spring Boot 3, Java 21, MongoDB
- **Infra:** AWS, Docker, Kubernetes
- **AI:** RAG Pipeline (gelecek)
- **CI/CD:** GitHub Actions, Vercel

## 📁 Proje Yapısı

```
apillo-landing/
```
